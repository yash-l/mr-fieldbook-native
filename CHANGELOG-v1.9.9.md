# v1.9.9

## Route build — stop cards now show full doctor info, like the Doctors list
Selecting a doctor for a route previously only showed the hospital and a bare
location status. Each stop card now also shows everything the Doctors list
card shows for that doctor:
- Specialty tag (e.g. PEDIA) and Core / Non-core badge
- Today's timing availability (e.g. "Available now • until 1:00 pm")
- Clinic access timing (Direct timed meeting / Appointment access / Card
  drop time), same coloring as the Doctors list (green = available now)
- Up to 3 focus product tags (e.g. MumMum 1, MumMum 2, Simyl MCT)
- The route-specific location status (Verified GPS / Saved GPS / Address
  only / Find address) folded into the first tag, prefixed with the stop
  letter so it's not lost among the other tags

Nothing else changed — same reorder/actions from v1.9.8.
