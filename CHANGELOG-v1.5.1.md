# MR One v1.5.1 — Multiple Doctor Filters

- Doctor filters can now be combined instead of replacing each other.
- AND across filter groups: availability + timing + address + type + area.
- OR inside Doctor Type and Area groups, so multiple types/areas can be selected together.
- Timing added and Timing missing remain mutually exclusive.
- Quick chips on Doctors page toggle independently.
- Filter button shows active-filter count.
- Filter sheet includes Apply and Reset all.
- Existing data, GPS, meetings and v1.5.0 workflow are unchanged.
