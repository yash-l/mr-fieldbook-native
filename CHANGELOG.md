# MR One v1.0

- New separate Android package `com.mrone.fieldapp`.
- Added Quick Doctor Details with type-to-find doctor, hospital, area, chemist, visit-frequency and timing preset controls.
- Quick Doctor Details automatically fetches one current GPS fix and shows nearby saved hospitals/doctors.
- Added per-doctor monthly visit target (1–4 per month) and optional custom gap.
- Smart Monthly Doctor Plan filters doctors already complete for the month.
- Smart route respects doctor meeting windows before nearest-chain distance.
- Smart plan automatically fetches current GPS and also supports searchable saved doctor/hospital starting points.
- Preserved DCR, chemist visits, RCPA, samples, expenses, POB/orders, tour program, voice capture, backup/restore and Excel reports.
