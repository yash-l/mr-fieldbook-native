# MR One v1.5.4 — One full manual doctor route

- Keeps every selected doctor in one continuous route list, including very large selections such as 28 or 138 doctors.
- Removes automatic route splitting and automatic route reordering from the selected-doctor route flow.
- User controls the complete route order with Up, Down and Move-to-position controls.
- Route progress uses one persistent Next Stop cursor; Navigate opens Google Maps only for the current doctor, then MR One returns to the same full route list.
- Doctors without a saved address/GPS remain in the same route as Find-address tasks instead of being removed.
- Missing-address lookup uses Doctor + Hospital/Clinic + doctor type + Area/City.
- Existing GPS/address verification and Google cross-check remain available.
